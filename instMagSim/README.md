# insMagSim
A Python package for astronomical instrument simulation for astronomical imaging system, developed for star sensor / CMOS detector magnitude simulation.

## Project Overview
`insMagSim` is an astronomical instrument magnitude simulation toolkit. 

This codebase was developed during research on astronomical optical instrument calibration and star photometry. 

Key use cases:
- End-to-end optical system simulation for star sensors
- Instrumental magnitude calculation


## dataset
Synthetic filter transmission, LAMOST Stellar Classification Template, Gaia G, BP, and RP filter transmissions are used in this work.
See [`data/README.md`](./data/README.md) for full description of the synthetic data generation.

## Requirements
Python >=3.10, recommended 3.11~3.14
