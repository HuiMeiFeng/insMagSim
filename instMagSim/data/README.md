# Dataset Description (trans_sim.csv)
The transmission in this folder is synthetic demonstration data.

The synthetic curves are generated by taking the low-frequency large-scale morphological trend of the original FGS measured curves as the baseline, overlaid with smoothed random perturbations.
The produced values **deviate substantially from the real FGS transmission measurements**.

This dataset is for simulation workflow demonstration only.
It shall not be treated as genuine hardware measurement data and cannot be applied for hardware performance assessment.

- `wavelength`: wavelength in nm
- `eff`: synthetic total efficiency, calculated as the product of FGS detector QE and main_optic
